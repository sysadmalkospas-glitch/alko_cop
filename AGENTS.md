# Как работать с задачами (для агентов и людей)

Все задачи проекта — GitHub issues, сводка с таблицей зависимостей и графом —
в задаче #1. Код задачи (`T07`) стоит в начале заголовка.

## Как выбрать задачу

1. Открой #1 и выбери задачу, у которой:
   * статус «открыта» и нет исполнителя;
   * **все** задачи из строки «Зависит от» закрыты;
   * нет пометки `[человек]` в заголовке (такие задачи делает человек:
     железо, сеть, учётные данные, проверка на реальных ПК).
2. Займи задачу: назначь себя исполнителем или оставь комментарий
   «Беру в работу» со ссылкой на свою сессию. Если задачу уже заняли — выбери другую.
3. Если задача оказалась больше, чем описано, или зависимость не закрыта
   по факту — напиши об этом в комментарии и не начинай.

## Как делать

* Ветка от основной: `t07-short-name` (код задачи в начале).
* Не выходи за рамки задачи. Найденное попутно — новая задача со ссылкой.
* Тесты обязательны:
  * сервер: `cd server && python -m pytest -q`;
  * агент: `cd agent && dotnet test AlkoCop.Agent.slnx`.
* Изменения схемы БД — только через миграцию Alembic (после T06).
* Не коммить секреты: пароли, токены бота, ключи — только в `.env` на сервере.
* Данные пациентов: скриншоты и заголовки окон не уходят во внешние сервисы
  (Telegram, LLM вне офиса) и не попадают в логи.
* Интерфейс и документация для пользователей — на русском; код, имена и
  сообщения коммитов — на английском.

## Как сдавать

* Pull request в основную ветку, в описании `Closes #<номер>` и что проверено.
* Если пункт «Готово, когда» нельзя проверить без реальной Windows или
  сервера — так и напиши в PR, задача остаётся открытой до проверки человеком.
* После слияния задача закрывается автоматически; проверь в #1, какие задачи
  стали доступны.
